# Larkspur brand basics

Supplied by Larkspur Marketing for internal tools. Ask Marketing (Ines Calder) about anything not covered here.

## Colours

| Name | Hex | Intended use |
|------|-----|--------------|
| Larkspur Violet | #3E2A8C | Headers, primary buttons |
| Larkspur Sky | #2E8BD8 | Links and secondary buttons |
| Ink | #1F2328 | Body text |
| Mist | #F6F8FA | Page and panel backgrounds |
| White | #FFFFFF | Cards and inputs |

## Type

- Use the system sans-serif font stack. No web fonts in internal tools.
- Body text 16 px; headings in Larkspur Violet.

## Voice

- Plain, short sentences. Dates written as "8 December 2026".
